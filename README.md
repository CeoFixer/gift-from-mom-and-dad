# Подарок от мамы и папы

Separate home for the two parent-made Mark City adventures.

- `/`: adventure selection
- `/comics/`: illustrated 2D comic game
- `/comics-3d/`: explorable 3D town with directional drawn character

The original game remains at https://ceofixer.github.io/mark-city/ . This project contains copies only; old links remain available. Future changes to these adventures belong here.

Run `npm test` and `npm start`. Static files are served by GitHub Pages from the main branch root. Three.js license: `vendor/THREE-LICENSE.txt`.

Includes English learning puzzles, family episodes, map editor, weather and time controls. Mark remains a multi-view sprite in the 3D world. Music is an original synthesized memory game, not an AJR recording.

Discovery Club: Science lab includes ideal projectile motion (Earth/Moon, adjustable angle, no air resistance) and additive RGB light mixing. Chess table provides three legal mate-in-one puzzles validated with chess.js 1.4.0 (license in vendor/CHESS-LICENSE.txt). Skateboard / K toggles faster movement and a visible board; normal movement, jumps and missions remain available. Both games link directly back to Mark’s original game and to the selection page.
